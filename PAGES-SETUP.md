# Enable the interactive Royal Cherry curtain page

The profile README uses `assets/royal-header.gif` because GitHub README does not provide arbitrary JavaScript or reliable hover-triggered CSS. The interactive curtain page is in `docs/index.html`.

1. Open `MaryamRazzaghNejad/MaryamRazzaghNejad`.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/docs`, then save.
5. Once the deployment completes, open `https://maryamrazzaghnejad.github.io/MaryamRazzaghNejad/`.

Hover or keyboard-focus the stage to open the curtains. On touch devices, use the button. The page respects `prefers-reduced-motion`.
